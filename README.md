# Frame — image and media hosting

An early, responsive React/Vite interface for a media-hosting service. This is the **framework/UI phase**; database, real authentication, durable media storage, and email delivery are intentionally not connected yet.

## Run locally

Requires Node.js 20.19 or newer (22.12+ recommended for Vite 8).

```sh
npm install
npm run dev
```

Open the local address printed by Vite. Sign in with any email and a password of at least eight characters. The first browser sign-in is a local preview account. Invite a member from **People**; they appear pending until approved. Sign out and sign in with that email to see the approval gate.

## What's in this phase

- Responsive login/sign-up and workspace shell
- Media library with image/video selection, drag-and-drop, local previews, search, and filters
- Unique random share token generation and expiry selector
- Shared-links view, copy link, revoke link, and delete media controls
- People list, invite UI, pending approval UI
- Optional recipient email handoff through the device's `mailto:` handler
- Domain setting uses the deployed host as a preview; actual custom domains are configured at the host/DNS provider
- Browser-local demo state to make the UI explorable without a database

## Important limitations before public use

This is a front-end prototype, **not a production file-hosting service**. Browser localStorage is not an identity system or a shared database; users only see data in their own browser. Upload previews use temporary browser object URLs. Refreshes or other devices are not guaranteed to retain uploaded files. Share URLs are shown/generated by the UI but there is no server route to serve them. Login, invitations, approvals, quotas, link expiry, revocation, and download counts are not securely enforced. Do not upload private or sensitive media or present this preview as a secure hosted service.

The next phase should add server-side authentication and authorization, a database, private object storage (for example S3-compatible storage), email provider integration, server-enforced upload limits, malware/type checks, and real public share/download endpoints.

## Global hosting preview

This is a static Vite site and can be deployed to Render Static Sites, Cloudflare Pages, Netlify, or Vercel:

- Build command: `npm run build`
- Install command: `npm ci`
- Publish/output directory: `dist`
- SPA fallback: rewrite unknown paths to `/index.html` (needed for client-side routes)
- Add the final custom domain in the hosting dashboard and configure the DNS records it provides.

The actual media backend should be deployed separately as a web service. Keep uploaded objects in private object storage, not the static site's deployment filesystem.
